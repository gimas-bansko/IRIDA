## Въведение

В реални софтуерни приложения работим с много еднотипни обекти: ученици, книги, продукти, автомобили, потребители или герои в игра. Обектно-ориентираното програмиране ни позволява да описваме тези обекти чрез класове, така че кодът да бъде по-организиран, четим и лесен за разширяване.

Класът събира на едно място **данните** за даден обект и **действията**, които той може да извършва. В този практикум ще създаваме собствени класове, ще инстанцираме обекти и ще тестваме тяхното поведение.

## След този урок ще можете да...

- дефинирате клас в Python по зададена спецификация;
- създавате обекти (инстанции) от клас;
- използвате атрибути и методи на обект;
- обяснявате ролята на `self`;
- откривате и поправяте чести грешки при работа с класове.

# 1. Основни понятия

## 1.1. Какво е клас?

**Клас** е шаблон или модел за създаване на обекти. Той описва:

- какви данни ще има всеки обект;
- какви действия ще може да извършва всеки обект.

Пример: класът `Student` може да описва общите характеристики на ученици — име, клас и метод за представяне.

```python
class Student:
    pass
```

Думата `pass` означава, че тялото на класа временно не съдържа инструкции.

## 1.2. Какво е обект?

**Обект** или **инстанция** е конкретен представител на даден клас.

Текстова схема:

```text
Клас Student
     │
     ├── student1: Мария, 11. клас
     └── student2: Иван, 11. клас
```

В примера `Student` е клас, а `student1` и `student2` са два различни обекта.

## 1.3. Какво са атрибути и методи?

- **Атрибут** — данна, която принадлежи на конкретен обект, например `name`, `age` или `health`.
- **Метод** — функция, дефинирана в клас. Той описва действие, което обектът може да извърши.

```text
Обект: книга
Данни (атрибути): заглавие, автор, брой страници
Действия (методи): показва информация, отваря се, затваря се
```

# 2. Дефиниране на клас в Python

## 2.1. Основен синтаксис

```python
class ClassName:
    # Атрибути и методи
    pass
```

### Правила за именуване

- Името на клас обикновено започва с главна буква: `Book`, `Car`, `GameCharacter`.
- При име от повече от една дума използваме стил `PascalCase`: `BankAccount`, `SchoolCourse`.
- Редовете в тялото на класа трябва да са с отстъп.

## 2.2. Конструкторът `__init__`

Конструкторът е специален метод, който Python извиква автоматично при създаване на обект. Чрез него задаваме началните стойности на атрибутите.

```python
class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade
```

### Какво означават редовете?

| Код | Обяснение |
|---|---|
| `class Student:` | Дефинира клас с име `Student`. |
| `def __init__(...)` | Дефинира конструктора. |
| `self` | Препратка към конкретния обект. |
| `name`, `grade` | Параметри, чрез които подаваме начални стойности. |
| `self.name = name` | Създава атрибут `name` на обекта. |
| `self.grade = grade` | Създава атрибут `grade` на обекта. |

# 3. Ролята на `self`

`self` е препратка към **конкретния обект**, с който работим в момента. Той позволява всеки обект да пази собствени стойности.

```python
class Student:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print(f'Казвам се {self.name}.')
```

При извикване:

```python
student1 = Student('Мария')
student1.introduce()
```

Python работи логически така:

```python
Student.introduce(student1)
```

Следователно в метода `self` сочи към обекта `student1`.

> **Запомнете:** В инстанционните методи `self` се записва като първи параметър. При извикване на метода чрез обект не подаваме `self` ръчно.

# 4. Създаване и използване на обекти

## 4.1. Инстанциране

Създаваме обект, като извикаме името на класа с нужните аргументи.

```python
student1 = Student('Мария', 11)
student2 = Student('Иван', 11)
```

Двата обекта са създадени от един и същ клас, но имат различни стойности на атрибутите.

## 4.2. Достъп до атрибути

Използваме точкова нотация:

```python
print(student1.name)
print(student2.grade)
```

## 4.3. Добавяне и извикване на метод

```python
class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def introduce(self):
        print(f'Казвам се {self.name} и съм в {self.grade}. клас.')


student1 = Student('Мария', 11)
student2 = Student('Иван', 11)

student1.introduce()
student2.introduce()
```

Очакван резултат:

```text
Казвам се Мария и съм в 11. клас.
Казвам се Иван и съм в 11. клас.
```

# 5. Практически пример: клас `Book`

Следващият пример показва клас за представяне на книга.

```python
class Book:
    # Конструкторът задава началните стойности на атрибутите.
    def __init__(self, title, author, pages):
        self.title = title
        self.author = author
        self.pages = pages

    # Методът използва атрибутите на конкретния обект.
    def show_info(self):
        print(f'Заглавие: {self.title}')
        print(f'Автор: {self.author}')
        print(f'Страници: {self.pages}')


# Създаваме два самостоятелни обекта.
book1 = Book('Под игото', 'Иван Вазов', 420)
book2 = Book('Малкият принц', 'Антоан дьо Сент-Екзюпери', 96)

# Извикваме метода за всеки обект.
book1.show_info()
print('---')
book2.show_info()
```

# 6. Пример: промяна на състоянието на обект

Методите могат не само да извеждат информация, но и да променят атрибути на обекта.

```python
class GameCharacter:
    def __init__(self, name, character_class, health):
        self.name = name
        self.character_class = character_class
        self.health = health

    def show_status(self):
        print(f'{self.name} | {self.character_class} | Здраве: {self.health}')

    def take_damage(self, damage):
        self.health -= damage


hero = GameCharacter('Арин', 'Магьосник', 100)
hero.show_status()

hero.take_damage(25)
hero.show_status()
```

Очакван резултат:

```text
Арин | Магьосник | Здраве: 100
Арин | Магьосник | Здраве: 75
```

В реда `self.health -= damage` се променя здравето на обекта, който е извикал метода.

# 7. Внимание: чести грешки и добри практики

## 7.1. Чести грешки

### Грешка 1: липсва `self`

```python
# Неправилно
def show_info():
    print(self.name)
```

```python
# Правилно
def show_info(self):
    print(self.name)
```

### Грешка 2: атрибутът не е свързан с обекта

```python
# Неправилно
class Student:
    def __init__(self, name):
        name = name
```

Тук не се създава атрибут на обекта.

```python
# Правилно
class Student:
    def __init__(self, name):
        self.name = name
```

### Грешка 3: неправилни отстъпи

```python
# Неправилно
class Car:
def __init__(self, brand):
    self.brand = brand
```

```python
# Правилно
class Car:
    def __init__(self, brand):
        self.brand = brand
```

### Грешка 4: извикване на метод без обект

```python
# Неправилно
Student.introduce()
```

```python
# Правилно
student = Student('Ани', 11)
student.introduce()
```

# 9. Cheatsheet: речник на новите термини

| Термин / синтаксис | Значение | Кратък пример |
|---|---|---|
| Клас | Шаблон за създаване на обекти. | `class Book:` |
| Обект / инстанция | Конкретен представител на клас. | `book1 = Book(...)` |
| Атрибут | Данна, която принадлежи на обект. | `self.title = title` |
| Метод | Функция, дефинирана в клас. | `def show_info(self):` |
| `__init__` | Конструктор; изпълнява се при създаване на обект. | `def __init__(self, name):` |
| `self` | Препратка към текущия обект. | `self.name` |
| Точкова нотация | Достъп до член на обект. | `book1.title` |
| Извикване на метод | Изпълнение на действие на обекта. | `book1.show_info()` |
