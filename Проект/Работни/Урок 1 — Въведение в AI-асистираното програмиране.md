AI-асистираното програмиране е полезно, когато го използваме като сътрудник: задаваме ясна задача, проверяваме резултата, тестваме кода и го подобряваме според изискванията на проекта.

# 1. Какво е AI-асистирано програмиране?

## Основна дефиниция

**AI-асистирано програмиране** е процес, при който програмистът използва инструмент с изкуствен интелект, за да подпомогне разработването на софтуер.

AI асистентът може да:

- предлага код според текстово описание;
- обяснява непознат код;
- открива възможни грешки;
- предлага тестови случаи;
- генерира документация и коментари;
- помага при рефакториране, тоест подобряване на структурата и четимостта на кода.

> **Важно:** AI асистентът е помощен инструмент. Отговорността за крайния код остава на програмиста.

## Текстова схема на работния процес

```text
Проблем / изискване
        ↓
Ясна инструкция към AI асистент
        ↓
Предложение за код или обяснение
        ↓
Преглед от програмиста
        ↓
Изпълнение и тестване
        ↓
Корекция, подобрение и документация
```

## Роля на програмиста

Програмистът не трябва само да копира резултата. Той или тя:

1. разбира задачата и уточнява изискванията;
2. формулира ясна инструкция;
3. проверява дали кодът е логически правилен;
4. тества с нормални, гранични и некоректни входни данни;
5. променя кода според нуждите на проекта;
6. защитава данните, авторските права и сигурността на приложението.

# 2. Кратка еволюция на софтуерната разработка

Развитието на инструментите не отменя основните принципи на програмирането. Алгоритмите, структурите от данни, тестването и добрата архитектура остават важни.

| Етап | Характеристика | Пример за работа на разработчика |
|---|---|---|
| Ръчно програмиране | Кодът се пише изцяло без интелигентни предложения | Писане на алгоритъм и проверка ред по ред |
| IDE и автоматизация | Средите за разработка предлагат подсказки, дебъгери и рефакториране | Автоматично довършване на имена и откриване на синтактични грешки |
| Библиотеки и облачни услуги | Използват се готови компоненти и услуги | Свързване с база данни или външен API |
| AI-асистирана разработка | AI подпомага създаването, обяснението и проверката на код | Генериране на функция по естественоезикова инструкция |

## Какво не се променя?

Независимо от използвания инструмент, добрият софтуер се основава на:

- ясно формулирани изисквания;
- правилен алгоритъм;
- четим и поддържаем код;
- защита на данните;
- тестване;
- документация;
- отговорност на разработчика.

# 3. AI асистенти за код

AI асистентите могат да работят в чат интерфейс, в браузър или директно в среда за разработка. Примери за такива инструменти са ChatGPT, Claude и GitHub Copilot.

## Какви задачи може да подпомогне AI?

| Задача | Примерна инструкция |
|---|---|
| Генериране на функция | „Напиши Python функция, която връща най-голямото число в списък.“ |
| Обяснение на код | „Обясни ред по ред какво прави този Python код.“ |
| Откриване на проблем | „Открий възможните грешки в този код и предложи корекция.“ |
| Създаване на тестове | „Предложи тестови случаи за функция, която изчислява отстъпка.“ |
| Документация | „Добави кратък docstring към тази функция.“ |

## Пример: от задача към код

### Стъпка 1: Формулиране на задача

```text
Създай Python функция is_even(number), която приема цяло число
и връща True, ако числото е четно, и False в противен случай.
Добави кратък docstring и два примера за извикване.
```

### Стъпка 2: Примерен AI-генериран код

```python
def is_even(number):
    """Връща True, ако number е четно цяло число."""
    return number % 2 == 0


print(is_even(8))   # Очакван резултат: True
print(is_even(11))  # Очакван резултат: False
```

### Стъпка 3: Проверка от програмиста

```python
# Нормален случай
assert is_even(4) is True

# Нечетно число
assert is_even(7) is False

# Граничен случай: нула също е четно число
assert is_even(0) is True

# Отрицателно число
assert is_even(-6) is True
```

### Обяснение на ключовия ред

```python
return number % 2 == 0
```

Операторът `%` връща остатъка при деление. Числото е четно, когато остатъкът при деление на 2 е 0.

# 4. Принципи за ефективна работа с AI асистент

## Правило 1: Задавайте ясна задача

Неясна инструкция:

```text
Напиши програма за оценки.
```

По-добра инструкция:

```text
Напиши Python функция average_grade(grades), която приема списък
от оценки от 2 до 6. Функцията да върне средната оценка като число
с два знака след десетичната запетая. При празен списък да върне None.
Добави примери за тестове.
```

## Правило 2: Посочвайте ограничения

Уточнявайте:

- езика за програмиране;
- входните данни;
- очаквания изход;
- специалните случаи;
- забранени или предпочитани библиотеки;
- изисквания за коментари, тестове и стил на кода.

## Правило 3: Проверявайте всеки резултат

AI може да генерира код, който:

- има синтактична грешка;
- не изпълнява всички изисквания;
- работи само за част от входните данни;
- използва неподходяща библиотека;
- съдържа неточно обяснение;
- изглежда правилен, но има скрит логически проблем.

## Правило 4: Не споделяйте чувствителна информация

Не въвеждайте в публични AI услуги:

- пароли, токени и API ключове;
- лични данни;
- съдържание от защитени бази данни;
- фирмен или училищен код, ако правилата не позволяват това;
- непроверени данни на други хора.

# 5. Внимание: чести грешки и добри практики

## Чести грешки

### 1. Сляпо копиране на код

AI може да даде работещ на пръв поглед код, който не изпълнява точно задачата.

**Решение:** изпълнете кода и го тествайте с няколко различни входа.

### 2. Твърде обща инструкция

Кратката и неясна задача често води до неточен или прекалено сложен отговор.

**Решение:** добавете контекст, вход, изход, ограничения и примери.

### 3. Игнориране на граничните случаи

Програма може да работи за обичайни стойности, но да даде грешка при празен списък, нула, отрицателни числа или невалиден вход.

**Решение:** тествайте нормални, гранични и некоректни случаи.

### 4. Приемане на AI обяснение като безусловно вярно

AI може да формулира уверено, но неточно обяснение.

**Решение:** проверявайте с документация, учебник, малък експеримент или мнение на преподавател.

## Добри практики

- Използвайте AI като партньор за идеи, а не като заместител на мисленето.
- Разделяйте голямата задача на малки проверими стъпки.
- Четете всеки ред код, преди да го използвате.
- Давайте смислени имена на променливи и функции.
- Добавяйте тестове и кратки коментари.
- Записвайте каква инструкция сте използвали и как сте променили получения код.
- Посочвайте, когато сте използвали AI при учебна или проектна работа, ако това се изисква.

# 7. Самопроверка

## Контролни въпроси

1. Какво е AI-асистирано програмиране?
2. Избройте две задачи, при които AI асистентът може да помогне на програмист.
3. Защо програмистът трябва да тества AI-генерирания код?
4. Кои елементи правят една инструкция към AI по-ясна и точна?

## Мини задача 1: Подобрете инструкция

Следната инструкция е твърде обща:

```text
Напиши програма за числа.
```

Пренапишете я така, че AI асистентът да създаде Python функция, която:

- приема списък от цели числа;
- връща сумата само на положителните числа;
- връща `0` при празен списък;
- съдържа кратък docstring;
- включва поне два тестови примера.

## Мини задача 2: Проверете код

Разгледайте кода:

```python
def calculate_average(numbers):
    return sum(numbers) / len(numbers)
```

1. Какъв резултат дава функцията при списък `[2, 4, 6]`?
2. Какъв проблем възниква при празен списък `[]`?
3. Напишете подобрена версия, която връща `None`, когато списъкът е празен.

Примерно решение:

```python
def calculate_average(numbers):
    """Връща средната стойност или None при празен списък."""
    if not numbers:
        return None

    return sum(numbers) / len(numbers)
```
