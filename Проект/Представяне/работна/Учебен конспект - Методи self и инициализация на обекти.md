## Въведение

В реалните приложения обектите не са само „кутии с данни“: те имат начално състояние и могат да извършват действия. Например обект „банкова сметка“ пази собственик и наличност, а чрез методи може да приема вноски, да проверява дали има достатъчно средства и да изчислява резултати.

В този урок ще научите как обектите получават начални данни чрез конструктора `__init__`, как работят методите и защо `self` е необходим, за да се работи с конкретен обект.

## След този урок ще можете да...

- инициализирате атрибути на обект чрез конструктора `__init__` и параметри по подразбиране;
- дефинирате и извиквате методи с параметри;
- връщате резултат от метод чрез `return`;
- различавате `print()` от `return`;
- проследявате как метод променя състоянието на конкретен обект;
- разпознавате основното предназначение на `@property`.

# 1. Основни понятия

| Понятие | Кратка дефиниция |
|---|---|
| **Клас** | Шаблон, по който се създават обекти. |
| **Обект** | Конкретен екземпляр на клас. |
| **Атрибут / поле** | Данни, които принадлежат на обекта, например име, точки или баланс. |
| **Състояние на обект** | Текущите стойности на неговите атрибути. |
| **Метод** | Функция, дефинирана в клас; описва действие на обекта. |
| **Конструктор** | Специалният метод `__init__`, който задава началното състояние на обекта. |
| **`self`** | Препратка към конкретния обект, върху който се изпълнява методът. |
| **Параметър по подразбиране** | Параметър, който има предварително зададена стойност, ако не бъде подаден аргумент. |

## Схема: клас, обекти и независимо състояние

```text
Клас Student
│
├── обект anna  → name: 'Ана', points: 10
└── обект boris → name: 'Борис', points: 0
```

Двата обекта са създадени по един и същ шаблон, но пазят **различни данни**. Промяна в `anna.points` не променя `boris.points`.

# 2. Ролята на `self`

## Какво означава `self`?

`self` е първият параметър на методите на обекта. Той сочи към **конкретния обект**, който е извикал метода.

Когато напишем:

```python
anna.add_points(5)
```

Python извиква метода за обекта `anna`. Вътре в метода `self` представлява именно `anna`.

```python
class Student:
    def show_name(self):
        print(self.name)
```

- `self` е конкретният обект;
- `self.name` е атрибутът `name` на този обект;
- не подаваме `self` ръчно при извикване на метода.

## Основно правило

Във всеки метод на обект `self` е първият параметър:

```python
class ClassName:
    def method_name(self, parameter):
        pass
```

За да достъпим или променим атрибут на обекта, използваме:

```python
self.attribute_name
```

# 3. Инициализация на обекти чрез `__init__`

## Какво е конструктор?

`__init__` е специален метод, който се изпълнява автоматично при създаване на обект. Той обикновено задава началните стойности на атрибутите.

```python
class Student:
    def __init__(self, name, points=0):
        self.name = name
        self.points = points
```

### Обяснение на ключовите редове

```python
class Student:
```
Създаваме клас с име `Student`.

```python
def __init__(self, name, points=0):
```
Дефинираме конструктор. Той получава име и точки. Ако точки не бъдат подадени, се използва стойност `0`.

```python
self.name = name
```
Записваме полученото име в атрибута `name` на конкретния обект.

```python
self.points = points
```
Записваме началните точки в атрибута `points` на конкретния обект.

## Създаване на обекти

```python
anna = Student('Ана', 10)
boris = Student('Борис')

print(anna.name)      # Ана
print(anna.points)    # 10
print(boris.name)     # Борис
print(boris.points)   # 0
```

При `Student('Борис')` не е подадена стойност за `points`, затова се използва параметърът по подразбиране `0`.

> **Запомнете:** `__init__` съдържа по две долни черти преди и след `init`.

# 4. Методи: действия на обектите

## Дефиниране на метод

Методът е функция в клас. Той може да използва атрибутите на обекта и да променя неговото състояние.

```python
class Student:
    def __init__(self, name, points=0):
        self.name = name
        self.points = points

    def add_points(self, value):
        self.points += value
```

Методът `add_points()` получава число чрез параметъра `value` и добавя това число към точките на текущия обект.

## Извикване на метод

```python
anna = Student('Ана', 10)
anna.add_points(5)

print(anna.points)  # 15
```

При извикването:

```python
anna.add_points(5)
```

- `anna` е обектът, към който се отнася `self`;
- `5` е стойността на параметъра `value`;
- променя се `anna.points`.

# 5. `print()` и `return` не са едно и също

## `print()` извежда информация

`print()` показва информация на екрана. Той е полезен за представяне на резултат или за проверка на междинни стойности по време на разработка.

```python
class Student:
    def show_points(self):
        print(self.points)
```

Този метод отпечатва точките, но не връща стойност, която да бъде използвана от друга част на програмата.

## `return` връща стойност

`return` изпраща резултата от метода обратно там, където методът е извикан. Тази стойност може да се запише в променлива, да се сравни или да се използва в израз.

```python
class Student:
    def __init__(self, name, points=0):
        self.name = name
        self.points = points

    def final_score(self):
        return self.points * 2

anna = Student('Ана', 15)
result = anna.final_score()
print(result)  # 30
```

## Сравнение

| Действие | `print()` | `return` |
|---|---|---|
| Показва стойност на екрана | Да | Само ако върнатата стойност бъде отпечатана |
| Дава стойност за по-нататъшна обработка | Не | Да |
| Подходящо за изчислителен метод | Не, ако резултатът ще се използва | Да |
| Пример | `print(self.points)` | `return self.points` |

### Неподходящ вариант

```python
class Student:
    def final_score(self):
        print(self.points * 2)

result = anna.final_score()
print(result)  # None
```

Променливата `result` съдържа `None`, защото методът не използва `return`.

# 6. Пълен пример: два независими обекта

```python
class Student:
    def __init__(self, name, points=0):
        # Начално състояние на обекта
        self.name = name
        self.points = points

    def add_points(self, value):
        # Променя точките само на текущия обект
        self.points += value

    def final_score(self):
        # Връща изчислен резултат
        return self.points * 2

    @property
    def status(self):
        # Връща текст според текущите точки
        if self.points >= 50:
            return 'Успешен'
        return 'Нужда от още точки'


anna = Student('Ана', 10)
boris = Student('Борис')

anna.add_points(15)

print(anna.name, anna.points)       # Ана 25
print(boris.name, boris.points)     # Борис 0
print(anna.final_score())           # 50
print(anna.status)                  # Нужда от още точки
```

## Какво се случва в примера?

1. Създават се два различни обекта: `anna` и `boris`.
2. `anna` започва с 10 точки, а `boris` започва с 0 точки.
3. Методът `anna.add_points(15)` променя само състоянието на `anna`.
4. `anna.final_score()` връща стойност `50`.
5. `anna.status` използва свойство, за да върне подходящ текст без извикване със скоби.

# 7. Кратка демонстрация на `@property`

## Какво прави `@property`?

`@property` позволява метод да се използва като атрибут при четене. Това е удобно, когато стойността се изчислява или когато искаме да осигурим контролиран достъп до данни.

```python
class Book:
    def __init__(self, title, copies=1):
        self.title = title
        self.copies = copies

    @property
    def is_available(self):
        return self.copies > 0

book = Book('Python основи', 1)
print(book.is_available)  # True
```

Обърнете внимание: използваме `book.is_available`, а не `book.is_available()`.

> На този етап е важно да разпознавате, че `@property` дава достъп до резултат от метод като до атрибут. По-късно ще разгледате и свойства за контролирано задаване на стойности.

# 8. Внимание: чести грешки и добри практики

## Чести грешки

### 1. Пропуснат `self`

```python
# Грешно
def add_points(value):
    self.points += value
```

```python
# Правилно
def add_points(self, value):
    self.points += value
```

### 2. Използване на локална променлива вместо атрибут

```python
# Грешно: променя се само локална променлива
points = points + value
```

```python
# Правилно: променя се атрибутът на обекта
self.points = self.points + value
```

### 3. Използване на `print()` вместо `return`

```python
# Неподходящо, ако резултатът трябва да се използва по-късно
def level(self):
    print('Начинаещ')
```

```python
# Подходящо
def level(self):
    return 'Начинаещ'
```

### 4. Споделяне на състояние по погрешка

Не създавайте атрибути извън `__init__`, ако искате всеки обект да има собствена стойност.

```python
# Нежелан общ атрибут за този случай
class Student:
    points = 0
```

```python
# Собствен атрибут за всеки обект
class Student:
    def __init__(self, points=0):
        self.points = points
```

## Добри практики

- Използвайте ясни имена: `add_score`, `balance`, `is_available`.
- Винаги поставяйте `self` като първи параметър на методите на обекта.
- Използвайте `return`, когато друг код трябва да получи резултат.
- Тествайте класа с поне два обекта.
- Проверявайте дали методът променя само състоянието, което трябва да промени.
- Използвайте параметри по подразбиране за разумни начални стойности.

# 9. Cheatsheet: речник и бърз справочник

| Термин / синтаксис | Значение | Кратък пример |
|---|---|---|
| `class Name:` | Дефинира клас | `class Student:` |
| `self` | Конкретният обект в метода | `self.name` |
| `__init__` | Конструктор за начални стойности | `def __init__(self, name):` |
| Атрибут | Данни на конкретен обект | `self.score = 0` |
| Метод | Действие на обект | `def add_score(self, points):` |
| Параметър | Входна стойност за функция или метод | `points` в `add_score(self, points)` |
| Параметър по подразбиране | Стойност, използвана при липсващ аргумент | `score=0` |
| `return` | Връща резултат от метод | `return self.score` |
| `print()` | Извежда стойност на екрана | `print(player.score)` |
| `@property` | Позволява четене на метод като атрибут | `player.level` |
| `object.method()` | Извиква метод на обект | `player.add_score(10)` |

## Мини задача 1: Брояч

Създайте клас `Counter`:

- конструктор `__init__(self, value=0)`;
- метод `increase(self, amount)`, който увеличава брояча;
- метод `current_value(self)`, който връща текущата стойност.

**Насока:** в метода за увеличаване променете `self.value`, а в метода за текуща стойност използвайте `return`.

```python
class Counter:
    def __init__(self, value=0):
        self.value = value

    def increase(self, amount):
        self.value += amount

    def current_value(self):
        return self.value

counter = Counter()
counter.increase(5)
print(counter.current_value())  # 5
```

# Обобщение

- `__init__` задава началното състояние на обекта.
- `self` сочи към конкретния обект, който работи с метода.
- Методите описват действията на обектите.
- `return` връща стойност за използване в програмата, а `print()` само я показва.
- Всеки обект има собствено състояние.
- `@property` позволява определени методи да се използват като атрибути при четене.
